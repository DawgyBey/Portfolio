# Sulav Nepal — Portfolio

React + Vite + Tailwind CSS (v3), plain JSX.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # outputs to dist/
```

## Structure

- `src/pages/Home.jsx` — assembles the page
- `src/sections/` — Nav, Hero, About, Timeline, Work, Papers, Github, Hire, Contact
- `src/components/` — Reveal, SectionHead, Marquee, Crosshair, NeuralCanvas
- `src/index.css` — global styles and animations
